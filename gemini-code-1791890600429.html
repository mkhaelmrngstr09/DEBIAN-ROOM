Pusat modul dan panduan teknis pembelajaran Administrasi Server Linux Debian dari tingkat dasar hingga remote access.

1. Pengertian & Keunggulan Linux Debian

Debian Linux adalah salah satu sistem operasi berbasis kernel Linux yang dikembangkan secara sukarela oleh komunitas global melalui Debian Project. Dikenal sebagai salah satu distribusi paling stabil dan aman, Debian menjadi fondasi utama bagi ratusan distro populer lainnya seperti Ubuntu, Kali Linux, dan Linux Mint.

Stabilitas Tinggi

Siklus pengujian paket yang ketat membuat Debian sangat ideal dijadikan fondasi server produksi tanpa reboot berkala.

Manajemen Paket APT

Memanfaatkan ekosistem paket .deb dan utilitas APT untuk instalasi, pembaruan, dan resolusi dependensi secara efisien.

Kompatibilitas Arsitektur

Mendukung berbagai arsitektur perangkat keras mulai dari x86_64, ARM (Raspberry Pi), hingga arsitektur mainframe.

Filosofi Open Source

Memegang teguh prinsip Debian Free Software Guidelines (DFSG) untuk menjamin kebebasan perangkat lunak.

2. Alur Instalasi Sistem Operasi Debian

  • 1. Media Booting

    Menyiapkan ISO (Netinst/DVD) dan flashing ke USB Flashdrive menggunakan Rufus atau BalenaEtcher.

  • 2. Boot & Installer

    Memilih mode Graphical Install (GUI) atau Text-Based Install pada bootloader GRUB.

  • 3. Lokasi & Bahasa

    Konfigurasi bahasa sistem, wilayah zona waktu, dan layout keyboard (Standard US).

  • 4. Jaringan & Akun

    Pengaturan Hostname, Domain, Password akun root, serta pembuatan user non-privilege.

  • 5. Partisi Disk

    Skema partisi Guided (Gunakan seluruh disk) atau Manual (Pemisahan /, /home, dan swap).

  • 6. Seleksi Perangkat Lunak

    Pemilihan komponen seperti Desktop Environment, SSH Server, dan Standard System Utilities.

3. Panduan Instalasi di VirtualBox

Langkah-langkah praktis membuat dan menginstal Debian di dalam lingkungan virtualisasi VirtualBox:

1. Membuat VM Baru

Buka VirtualBox → Klik New. Isi Nama Mesin (contoh: Debian-Server), Tipe: Linux, Versi: Debian (64-bit).

2. Alokasi Memori & CPU

Tentukan RAM minimal 1024 MB (1 GB) untuk CLI, atau 2048 MB (2 GB) untuk GUI. Alokasikan 1-2 vCPU.

3. Hard Disk Virtual

Pilih Create a Virtual Hard Disk Now → Format VDI (Dynamically Allocated) → Ukuran minimal 10 GB - 20 GB.

4. Mount Image ISO

Masuk ke Settings → Storage → Klik ikon CD bertuliskan Empty → Cari dan pilih file ISO Debian Anda.

5. Konfigurasi Network

Pada menu Settings → Network → Ubah Attached to menjadi Bridged Adapter atau NAT.

6. Jalankan Instalasi

Klik Start, pilih opsi Graphical Install, lalu ikuti petunjuk hingga proses selesai dan minta reboot.

Spesifikasi Rekomendasi Virtual Machine

Komponen Minimal (CLI Server) Rekomendasi (GUI Desktop)
RAM 512 MB - 1 GB 2 GB - 4 GB
Penyimpanan 8 GB 20 GB
CPU Core 1 Core 2 Core
Tipe Network Bridged / Host-Only NAT / Bridged

4. Instalasi & Konfigurasi OpenSSH Server

SSH (Secure Shell) memungkinkan akses administrasi server jarak jauh secara terenkripsi melalui jaringan.

Langkah Instalasi Paket SSH

Masuk ke terminal Debian sebagai superuser (root), lalu jalankan perintah berikut:

# 1. Perbarui indeks repositori paket
apt update

# 2. Instal paket OpenSSH Server
apt install openssh-server -y

# 3. Aktifkan dan jalankan layanan SSH
systemctl enable ssh --now

# 4. Verifikasi status operasional layanan
systemctl status ssh

Memeriksa Alamat IP Server

Gunakan perintah berikut untuk mengetahui IP Address server yang akan di-remote:

ip a # atau jalankan: hostname -I

5. Cara Remote Server Debian

Melalui CMD / PowerShell

Gunakan perintah bawaan terminal Windows:

ssh user_debian@192.168.1.50
*Ganti 192.168.1.50 dengan IP Debian Anda.

Melalui Aplikasi PuTTY

  1. Buka aplikasi PuTTY.
  2. Isi Host Name (or IP address).
  3. Pastikan Port: 22 & Connection type: SSH.
  4. Klik Open dan masukkan kredensial login.

Tips Keamanan SSH

  • Hindari mengaktifkan login langsung sebagai root via SSH pada file /etc/ssh/sshd_config (set PermitRootLogin no).
  • Ubah port default SSH (22) ke port kustom untuk menghindari serangan brute-force otomatis.
  • Gunakan autentikasi berbasis kunci (SSH Key Pair) daripada kredensial password polos.
